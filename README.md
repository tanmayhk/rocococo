# rocococo
_(**ro**bust **co**ngressional **co**sponsorhsip **co**nnections)_

Cleaning up bill data from ProPublica data store, extending Mayhew's legislative productivity data, and applying methodology from [Legislative Success in a Small World: Social Network Analysis and the Dynamics of Congressional Legislation](https://tam.cas.vanderbilt.edu/papers/smallworld.pdf) for longer time periods.
